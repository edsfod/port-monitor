说明

这页是什么

本机所有 TCP 监听端口与 UDP 端点，一行是「协议 + 端口 + 进程」；同一进程在多个地址上开同一端口（如 0.0.0.0 与 ::）合成一行，地址逐个列出。

「它在做什么」从哪来

自己的工具
两种认法：一是带 web-kit 外壳的本地网页服务（问它的 /api/ping，回的进程号与监听进程相同），名字取自它的回答；二是命令行或路径位于设置 tool_dirs 所列目录下的进程（settings.json），名字取自脚本所在目录。用途取自脚本开头说明的首行。
内置程序表 / 内置端口表
写在 port_monitor.py 里的常见程序与常见端口说明，含「是否正常」。程序表对该端口有专门说明时排在端口表前面，否则排在后面。
Windows 服务
该进程承载的服务（显示名与描述），svchost 主要靠它。
文件信息
可执行文件的「文件说明」与「公司」。
看不出
以上都没有，只给出进程名与路径。

一行可能同时有几条来源，按上面的顺序排；行内显示第一条，展开看全部。

谁能连进来

仅本机
只监听 127.0.0.1 或 ::1，别的机器连不到。
局域网可访问
监听 0.0.0.0 / ::（所有网卡）或某块网卡的地址。地址后注明是哪块网卡：vEthernet 开头的是 Hyper-V / WSL 的虚拟网卡，只有本机的虚拟机能连到。本页不查防火墙，防火墙仍可能挡住外来连接。

停止

只对自己的工具提供。web-kit 网页服务请它自己退出（/api/shutdown）；其它工具自己支持 --stop 的，用它的 --stop 正常退出；不支持或 8 秒内没退出的，结束进程（taskkill /T /F）。系统与第三方进程只显示，不提供结束。

读不到的字段

不以管理员身份运行时，系统服务与以系统账户运行的程序（如 Clash Verge 内核）的路径、命令行读不到，显示「读不到（需要管理员权限）」；端口、进程名与服务信息不受影响。

后台运行

服务由 pythonw 在后台运行，没有窗口。本页开着时每 60 秒发一次心跳；关掉页面后连续 30 分钟没有请求，服务自动退出。手动停止：pythonw port_monitor.py --stop。
